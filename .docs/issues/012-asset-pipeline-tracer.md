## What to build

一条贯穿全部层次的最小资产管线：让**一个包**的展示纹理从全分辨率母本走到浏览器，中途经过降采样、外部对象存储和自定义域，页面渲染与现在完全一致。

先核实 Cloudflare R2 免费额度的确切数字。按分级降采样后的估算，全量约 3900 个包的展示资产约 790MB，预期在额度内；若不足，就地把分级上限统一收紧到 256（估算约 320MB），并在本 issue 内记录该调整。这个数字是整个方案的前置条件，不能带着假设往下走。

降采样规则实现为纯函数：输入文件名与原始尺寸，输出目标尺寸或"保持原样"。分级上限为图集类（粒子、物品栏、GUI 图标、原始物品栏）≤512，物品与方块类 ≤256，包图标压到 256，封面保持原样。只允许 2 的幂次缩放且必须最近邻采样——护甲、GUI、物品栏三个预览按固定坐标切图集精灵，非 2 幂次会让切片错位，非最近邻会毁掉像素风格。

资产远端实现为独立模块，形状照抄现有的 GitHub 材质包远端：导出工厂函数、URL 构造函数、对象名与路径校验函数。材质包名普遍含 Minecraft 色号、井号与空格，URL 编码在既有代码里已被证实是出错点，编码逻辑必须集中在这一个模块里。

前端引用缩略图的位置改为从资产基址常量拼接，基址在构建期注入，本地开发回落到本地目录。本 issue 只需让这一个包的资产走新路径并正确显示，其余包保持原样。

- [ ] 降采样规则纯函数存在，其测试覆盖：四类文件各自的目标尺寸、任何输入都只产生 2 的幂次缩放比、原始尺寸低于上限时返回"保持原样"、封面在任何输入尺寸下都保持原样
- [ ] 资产远端模块存在，其测试用本地 stub 承接请求、不接触真实远端，覆盖：拒绝穿越路径与非法对象名、含色号与井号与空格的包名产生正确的资产 URL、重复上传同一对象不产生副本、中断后重跑跳过已验证对象
