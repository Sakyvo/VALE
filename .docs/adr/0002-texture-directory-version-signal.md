# 以纹理目录识别高版本材质，而非 pack_format

VALE 按 Plot ADR 0003 的信号判定材质包所属的 Minecraft 世代：复数 `textures/items/` 或 `textures/blocks/` 是低版本证据并优先，否则单数 `textures/item/` 下存在贴图、或存在单数 `textures/block/` 即判为**高版本材质**。不采用 `pack_format`、mcmeta 可解析性或文件名——真实 1.8 流通包的版本声明普遍不可靠，按声明阻断会造成严重误杀，而目录布局是渲染路径实际依赖的事实。信号边界是命中的内包，不向上传播到容器外壳，也不影响同容器的兄弟包。

高版本材质获得独立分类而非并入**非法材质**或 **Repairable pack**：它既无损坏可言（读得开、贴图完整），也无从修复（修复的定义是转换为 Normal pack，而它只是超出 1.7/1.8 范围）。混入非法材质会让审计账本失真，使"损坏的垃圾"与"完好但版本不符"无法分开复查。因此它被忽略跳过——不上传、不进 List、写入审计记录，不中断整批上传，且不可被 `--skip-blockers` 绕过（它是确定性排除，不是待人工复查的阻塞）。
